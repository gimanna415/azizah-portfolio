SMKConnectStudent Job Portal

RoleFull-Stack Developer
Year2024
TypeWeb Application
Duration3 months
SMKConnect is a scalable job portal designed specifically for vocational school (SMK) graduates. It bridges the gap between talented young job seekers and employers looking for skilled, ready-to-work candidates. The platform handles user registration, job postings, application tracking, and an admin dashboard for managing listings.
Key Features

Multi-role Auth

Separate dashboards for students, employers, and admins with role-based access control.

Smart Search & Filter

Filter jobs by category, location, and skill requirements for precise matching.

Application Tracking

Real-time status updates from applied, reviewed, interviewed, to accepted.

Admin Management

Full CRUD control over job listings, user accounts, and platform analytics.

Technology Stack
  • PHP
  • Laravel
  • MySQL
  • Blade Templates
  • Tailwind CSS
  • JavaScript

Outcome

Successfully connected 200+ students with potential employers during the pilot phase. The admin dashboard reduced manual job posting management time by 60%.
